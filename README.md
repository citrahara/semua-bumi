# Semua Bumi

Gim edukasi eksplorasi bola bumi 3D berlabel seluruh **195 negara berdaulat PBB** (193 negara anggota ditambah Vatikan dan Palestina) beserta bendera asli masing-masing negara, terinspirasi oleh suasana perjalanan dalam novel *Semua Ikan di Langit* karya Ziggy Zezsyazeoviennazabrizkie.

## Fitur Utama

1. **Bola Bumi 3D Berlabel 195 Negara + Bendera SVG Lokal**: Putar dan perbesar bola bumi secara bebas; bendera dan nama negara tampil langsung di permukaan bumi. Ketuk label negara mana saja atau cari lewat menu Atlas 195 Negeri untuk mempelajari **Hasil Bumi & SDA**, **Buku**, **Film**, **Karya & Sains**, serta fakta unik setiap negeri.
2. **Tokoh 3D Beliau yang Selalu Menghadap Pemain**: Setelah masuk akun, tokoh 3D **Beliau** berdiri tegak menghadap langsung ke arahmu dengan mata bercahaya, kedipan lembut, senyum hangat, dan lentera kecil ditemani enam **ikan julung-julung terbang** yang mengitarinya.
3. **Bus Damri 3D dan Obrolan Offline**: Bus Damri ("Saya") ikut mengorbit mengelilingi bumi, dapat berpapasan langsung dengan Beliau di langit (*Pertemuan di Langit*), dan berfungsi sebagai pemandu obrolan 100% offline yang mengenali seluruh 195 negara tanpa memerlukan API key AI.
4. **Tantangan Opsional**: Selain mode utama **Jelajah**, tersedia tiga tantangan cepat (**Tancap Peta**, **Duel Tahun**, dan **Benang Merah**).

## Menjalankan Secara Lokal

```bash
python -m http.server 8090
```

Buka `http://localhost:8090` di browser modern dengan dukungan WebGL.
